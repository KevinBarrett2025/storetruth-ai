# StoreTruth AI Codex instructions

## Launch roadmap reporting

- Treat `docs/storetruth_app_launch_roadmap.md` as the canonical launch-status
  document.
- Update it whenever completed work changes app-launch status.
- End every completion report with:
  - the repository-relative roadmap path
  - a clickable absolute `file://` link to the roadmap
  - a clickable `file://` link to the containing `docs` folder
  - a fallback macOS Finder command using `open -R`
- Do not claim the roadmap was updated unless it was actually changed and
  committed when appropriate.
- Do not mark work complete without repository or validation evidence.
